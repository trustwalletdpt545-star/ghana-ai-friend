# Ghana Ai Friend

Build an INTERNATIONAL AI CHATBOT - answers everything, like ChatGPT but better for Ghana + World

DESIGN:

- Beautiful ChatGPT-style: dark mode, sidebar with chat history, big chat area

- Top: "Comfortable AI 🌍 - Ask Me Anything International"

- Center: Example questions: "Explain nursing in Twi", "How to cook jollof?", "Teach me math", "What's happening in Ghana?", "Write CV for me"

FEATURES - MUST HAVE:

- Chat input at bottom with Send button and voice input mic

- Answers EVERYTHING: nursing, education, Ghana culture, coding, health, jokes, translations (English, Twi, Ga, Ewe, French)

- Streaming response like ChatGPT (typewriter effect)

- Sidebar: New Chat, Chat History, Clear

- Markdown support: code blocks, bold, lists

- Copy answer button

- Like/dislike buttons

- Regenerate answer

- Language selector: Auto-detect user language and answer in same language

- Country flag shows where question comes from

- Works offline with smart canned answers + online AI

BONUS INTERNATIONAL:

- Knows Ghana: Accra, Kumasi, nursing schools, BECE, WASSCE, etc

- Knows nursing: Can answer NCLEX, RGN, all nursing questions

- Can translate Twi <-> English instantly

- Footer: "Built in Ghana for the World 🇬🇭🌍 - nursecare-gh + comfortable-ai"

Make it feel like real ChatGPT but Ghanaian and international. Publish ready.
